> Personal utility extension. Issues and feedback are welcome.

JSONTool is a local-first browser extension for Chromium-based browsers (Chrome, Edge), designed for JSON formatting, validation, interactive table presentation, and side-by-side diff comparison. The user interface is built strictly around the Fluent 2 design language.

All data is stored directly in browser local storage (`chrome.storage.local`).

## Features

### UI and Interaction

- Built with Fluent 2 design guidelines, supporting both light and dark themes.
- Tab bar adheres to Fluent 2 vertical navigation standards with smooth collapse/expand animations (persistent initial badges, elastic title transition, float preview popover), smooth left sliding active indicator (GPU accelerated), multi-tab management with context menus (Close, Close Others, Close Below, Duplicate, Rename), middle-click closing, and clear hover feedback.
- Automatic workspace session persistence that restores open tabs across browser restarts.

### Editor and Formatting

- Powered by CodeMirror 6, providing syntax highlighting, code folding, and regex find/replace.
- Supports both standard JSON and loose JavaScript Object syntax (handles unquoted keys, etc.).
- One-click format, compact, and recursive object key sorting.
- Configurable "Auto Detect Format" toggle to prevent unwanted blocking while drafting.
- Persistent code folding state maintained independently per tab.

### Table View

- Transform top-level or nested JSON arrays into interactive data tables.
- Resizable column widths, multi-column sorting, and instant keyword filtering.

### Diff Comparison

- Side-by-side visual diff comparison with exact change highlighting.
- Independent formatting and compact controls on the comparison pane.

### Internationalization (i18n)

- Built-in Chinese and English interfaces with automatic language detection and manual switching.

## Tech Stack

- **Core Framework**: Vue 3 (Composition API)
- **State Management**: Pinia
- **Code Editor**: CodeMirror 6 (@codemirror/lang-json, @codemirror/merge)
- **Styling**: Custom Fluent 2 SCSS
- **Build Tool**: Vite + @crxjs/vite-plugin

## Development and Build

### Prerequisites

- Node.js >= 16
- npm / pnpm

### Commands

```bash
# 1. Install dependencies
npm install

# 2. Start development mode with HMR
npm run dev

# 3. Build for production
npm run build
```

## Installation

1. Open the extension management page in your Chromium browser (`chrome://extensions/` or `edge://extensions/`).
2. Enable "Developer mode" in the top-right corner.
3. Click "Load unpacked" and select the `dist/` directory generated by the build.
4. Alternatively, download the pre-packaged archive from GitHub Releases (`JSONTool-ChromeWebStore-v0.8.0.zip`), unzip it, and load the unpacked directory.
